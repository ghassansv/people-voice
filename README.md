# صوت الناس

تطبيق عربي بسيط لجمع تأييد الناس لرسالة عامة. الواجهة تُنشر على GitHub Pages، والبيانات تُحفظ في مشروع Supabase مستقل.

## ما تم بناؤه

- صفحة عامة لعرض الرسالة وتسجيل الاسم والهاتف والعنوان الاختياريين.
- عدّاد حقيقي للمشاركين.
- حفظ نسخة الرسالة التي وافق عليها كل مشارك.
- لوحة إدارة محمية لتعديل الرسالة وفتح أو إغلاق التسجيل.
- عرض أحدث المشاركين والبحث فيهم.
- تصدير جميع البيانات إلى CSV يفتح مباشرة في Excel.
- قواعد Row Level Security تمنع الجمهور من قراءة بيانات المشاركين.
- نشر تلقائي إلى GitHub Pages عند الدفع إلى فرع `main`.

## ربط Supabase

1. أنشئ مشروعًا جديدًا مستقلًا في Supabase.
2. افتح **SQL Editor** وشغّل الملف `supabase/schema.sql` كاملًا.
3. من **Authentication > Users** أنشئ مستخدم المسؤول بالبريد وكلمة المرور.
4. في SQL Editor نفّذ السطر التالي بعد استبدال البريد:

```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'YOUR_ADMIN_EMAIL';
```

5. من **Project Settings > API** انسخ Project URL والمفتاح العام Publishable أو anon.
6. ضع القيمتين في `dist/config.js`.

المفتاح العام مسموح أن يظهر في المتصفح لأن الحماية تعتمد على RLS. لا تضع مفتاح `service_role` في أي ملف داخل الموقع أو GitHub.

## التجربة المحلية

من مجلد المشروع شغّل:

```powershell
python -m http.server 4173 --directory dist
```

ثم افتح:

- الصفحة العامة: `http://localhost:4173/`
- لوحة الإدارة: `http://localhost:4173/admin.html`

## النشر على GitHub Pages

ارفع المشروع إلى مستودع GitHub، ثم افتح **Settings > Pages** واختر **GitHub Actions** كمصدر للنشر. بعد كل تحديث على `main` ستُنشر محتويات `dist` تلقائيًا.

## تنبيه خصوصية

تأييد رسالة سياسية قد يُعد بيانات شخصية حساسة حسب الدولة. راجع القوانين المحلية، حدّد مدة الاحتفاظ، ووفّر وسيلة واضحة لطلب حذف البيانات قبل نشر الحملة للعامة.
